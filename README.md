# Sellevate

Sellevate помогает отделам продаж отрабатывать разговоры с покупателями. Менеджер проходит уроки, разбирает ошибки и тренируется на карточках компаний. Руководитель назначает практику и разбирает результаты своей команды. Администратор платформы управляет организациями и библиотекой контента.

## Запуск на своей машине

Понадобятся Docker и Docker Compose с поддержкой `!override`. В корне выполните следующие команды.

```sh
cp .env.example .env
docker compose --env-file .env -f compose.yaml -f docker-compose.local.yml config --quiet
./scripts/docker-local-up.sh
```

Перед запуском заполните в `.env` пароли хранилищ, ключ подписи JWT и межсервисный секрет. Для почты, внешней авторизации и платных моделей нужны ключи соответствующих провайдеров. Откройте [интерфейс](http://localhost:3000) и [проверку шлюза](http://localhost:5001/healthz). Команда `./scripts/docker-local-down.sh` останавливает окружение с сохранением томов.
