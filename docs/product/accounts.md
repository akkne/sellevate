# Учётные записи и связь

Открытая регистрация создаёт учётную запись. Членство появляется после принятия приглашения. При включённой проверке почты пользователь получает одноразовый код; повторная отправка ограничена интервалом. Обновление JWT использует refresh cookie. Политики платформы и организации различают администратора и суперадминистратора.

Публичная заявка на демо включает контактные данные. Одобрение заявки и создание организации — отдельные операции. Выдача доступа первому администратору использует приглашение. Для проверки используйте тестовый адрес и почтовый транспорт из [настроек](../../.env.example).

Пользователь редактирует профиль и аватар. Фотографии хранятся в S3-совместимом хранилище. Друзья, переписка и фотографии обсуждений обслуживаются Social. Скрытый пункт обсуждений сохраняет существующие записи и маршруты. Предпочтения уведомлений сохраняются на сервере отдельно для каждого пользователя. Контракты [Identity](../contracts/http/identity.md), [Social](../contracts/http/social.md), [Notification](../contracts/http/notification.md).
