# Возможности продукта

| Участник | Сценарий | Результат и ограничения |
| --- | --- | --- |
| Гость | Запрос демо, регистрация, принятие приглашения | Запрос получает статус, учётная запись без членства видит ожидание приглашения |
| Менеджер | Дерево навыков, теория, упражнения и повтор ошибок | Попытка сохраняет ответ и оценку, пропуск учитывается в прохождении урока |
| Менеджер | Текстовая или голосовая тренировка | Диалог заканчивается разбором, доступ зависит от настроек голоса и квоты |
| Менеджер | Работа с компанией | Контакты, этап, следующий шаг, заметки и тренировка в контексте компании |
| Руководитель | Программа и назначения | Сроки, порог качества, повторы, статус команды и обратная связь |
| Руководитель | Подготовка материалов | Из исходного материала формируется структура, после подтверждения — упражнения и черновики |
| Администратор | Управление организациями, пользователями и библиотекой | Политики платформы и организации проверяются отдельно |
| Пользователь | Друзья, сообщения и уведомления | Настройки доставки сохраняются на сервере. Раздел обсуждений скрыт из навигации, маршруты сохранены |

Маршруты интерфейса перечислены в [карте экранов](screens.md), серверные операции — в [контракте API](api-schema.md).
