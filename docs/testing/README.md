# Проверки и ручная приёмка

Сервер собирается в Release. [Скрипт](../../scripts/verify-backend.sh) запускает каждый тестовый проект отдельно, проверяет формат, ссылки между проектами и модели миграций. Набор [RouteParity.Tests](../../tests/backend/RouteParity.Tests) сверяет контроллеры со шлюзом. Все клиентские сценарии Vitest запускает `npm test` из `frontend/`.

Для интеграционных тестов используйте отдельный PostgreSQL 17, MongoDB 8 и Redis 7. Параметры по умолчанию — localhost, порты 5433, 27017, 6379. Учётная запись PostgreSQL для локальных тестов — `st`, пароль `st_secret`; тестам требуются права создавать временные базы и роли. Порты меняют `LOCAL_POSTGRES_PORT`, `LOCAL_MONGO_PORT`, `LOCAL_REDIS_PORT`. CI создаёт собственные контейнеры. Для интеграционных тестов Learning нужен клиент `psql` в PATH. После миграций EF тест применяет [индексы организаций](../../infra/tenancy/sql/40.10_learning_organization_indexes_concurrently.sql) к своей временной базе. При недоступности хранилища некоторые тесты пропускаются, поэтому при приёмке проверьте число пропусков.

| Сценарий | Проверка результата |
| --- | --- |
| Регистрация и приглашение | Неверный и просроченный код, отсутствие членства, принятие приглашения, выход |
| Урок и повтор | Корректный и ошибочный ответ, пропуск, возврат, получение результата после временной ошибки |
| Голос и диалог | Разрешение и отказ микрофона, начало и завершение, исчерпание квоты, разбор |
| Компания | Создание контакта, смена этапа, журнал, напоминание, запрет чужого объекта |
| Организация | Назначение, порог качества, повтор, профили двух организаций, ограничения ролей |
| Уведомления | Прочтение, переключение предпочтений, перезагрузка, сохранение при смене устройства |
| Интерфейс | Клавиатура, мобильная ширина, светлая и тёмная темы, подписи RU/EN, пустой список и ошибка сети |

Внешние вызовы проверяйте с тестовой учётной записью. Для приёмки смены схемы выполните отдельную [проверку двух организаций](tenancy.md).
