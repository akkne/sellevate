# Fish Audio S2.1 Pro Free

Действующая модель `s2.1-pro-free` озвучивает реплики AI-собеседника. Для подключения задайте `TTS_PROVIDER=fish`, `FISH_AUDIO_API_KEY` и включите голос в нужном режиме диалога. Стандартный голос выбирает провайдер. Для фиксированного голоса укажите в режиме Fish Audio reference ID из 32 шестнадцатеричных цифр.
