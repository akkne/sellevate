# Локальные модели Qwen для голосового звонка

Локальная генерация полного текста на Apple Silicon. Проверочная конфигурация использует llama.cpp b12816, Metal, GGUF Q4_K_M и один слот. Веса Qwen распространяются по лицензии Apache 2.0. Сценарий, история и ответ обрабатываются в памяти локального сервера. Короткое описание организации или сценария также передаётся рядом с текущим вопросом, чтобы собеседник мог сверить предположения звонящего с исходными фактами. Для озвучки AI передаёт готовый текст действующему TTS-провайдеру. Дата проверки — 27 ноября 2026 года. [Карточка модели Qwen](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) · [Сборка весов](https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF)

Для запуска на Mac задайте `LLAMA_SERVER_BIN` и `LOCAL_VOICE_WEIGHTS` путями к серверу и файлу весов, затем запустите `scripts/dev-voice-model.sh`. В локальном Compose задайте `LOCAL_VOICE_LLM_URL=http://host.docker.internal:15142/v1/chat/completions` и пересоздайте `ai`. Пустой URL отключает локальный маршрут. Для проверки отправьте реплику в голосовом звонке и измерьте время от отправки до события воспроизведения аудио в браузере. [Скрипт запуска](../../scripts/dev-voice-model.sh) · [Адаптер](../../backend/ai-service/Ai/Infrastructure/Http/LocalVoiceCompletionClient.cs) · [Контракт](../../backend/ai-service/Ai/Infrastructure/Http/LocalVoiceCompletionClient.api.md)

Опция `FISH_AUDIO_LOW_LATENCY_MP3=true` включает MP3 с низкой задержкой. Совместимый браузер начинает воспроизведение по мере поступления звука. Fish получает весь текст реплики и один идентификатор голоса одним запросом. [Контракт голосового ответа](../api-schema.md#голосовой-ответ)

При запуске скрипт один раз прогревает модель общими инструкциями для звонков. Для прогрева нужны `curl` и `jq`. Этот запрос выполняется на Mac, использует один выходной токен и не содержит данных сессии.

## Qwen3.5-9B

Для модели `qwen3.5-9b` используется текстовая часть Qwen3.5-9B, GGUF Q4_K_M и режим без скрытого рассуждения. Укажите `LOCAL_VOICE_LLM_MODEL=qwen3.5-9b` в корневом `.env`. Скрипт запуска использует это имя для прогрева и запросов приложения. Для голосовой практики нужны только текстовые веса. [Карточка Qwen](https://huggingface.co/Qwen/Qwen3.5-9B) · [Проверенная сборка GGUF](https://huggingface.co/unsloth/Qwen3.5-9B-GGUF/blob/3885219b6810b007914f3a7950a8d1b469d598a5/Qwen3.5-9B-Q4_K_M.gguf)

Положите веса в `.local-run/voice-lab/qwen3.5-9b.gguf` или задайте путь через `LOCAL_VOICE_WEIGHTS`. Проверенный файл занимает 5 680 522 464 байта, SHA-256 — `03b74727a860a56338e042c4420bb3f04b2fec5734175f4cb9fa853daf52b7e8`. После смены модели перезапустите процесс и пересоздайте локальный контейнер `ai`. Чтобы вернуться к быстрой модели, укажите `qwen3-4b-instruct-2507` и запустите её тем же способом.
