# OpenAI Codex · gpt-6.2-astra

Активный провайдер текстовых промптов. Модель по умолчанию — `gpt-6.2-astra`, уровень рассуждения — `high`. Идентификатор и уровень сверены с каталогом локального CLI 0.172.0 25 ноября 2026 года. Доступ определяет аккаунт Codex.

Для реплик в голосовом звонке можно указать отдельную модель в `CODEX_VOICE_MODEL`, например `gpt-6-luna`, проверенную в локальном звонке 27 ноября 2026 года. При пустом значении звонок использует `CODEX_MODEL`. Для голосовых реплик воркер использует уровень рассуждения `low`. Расход записывается для фактически выбранной модели.
