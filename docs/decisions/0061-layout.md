# Структура проекта и проверка контрактов

Дата — 25 ноября 2026 года.

**Контекст.** Сервисам нужен общий набор проверок. Отдельно написанный справочник HTTP и схемы базы расходился с реализацией.

**Решение.** Серверный код находится в `backend/`, приложения Next.js — в `frontend/`, серверные тесты — в `tests/backend/`. Vitest использует зависимости, алиасы и окружение пакета frontend. В CI проверяются формат, границы, тесты с хранилищами, сборка, конфигурация и договорённости Git. Схемы HTTP собираются из метаданных MVC, DDL — из EF Core.

**Последствия.** Изменение контроллера или модели требует обновить соответствующий контракт. Рабочие команды разработки и пути к томам в Compose сверяются при изменении структуры. [Проверки](../git/README.md).
