# 0063. Fish Audio для озвучки тренировочных звонков

27 ноября 2026 года. Принято.

AI-сервис выбирает Fish Audio при `TTS_PROVIDER=fish`. Для локальной тренировки адаптер явно запрашивает бесплатную модель `s2.1-pro-free`. По умолчанию используется Yandex SpeechKit. Оба провайдера возвращают WAV через существующий интерфейс, используют общий кэш и учитывают синтез в организации. Ключ Fish Audio хранится на стороне AI-сервиса.
