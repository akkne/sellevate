# Исполнение текстовых промптов через Codex

25 ноября 2026 года.

**Контекст.** Чат, генерация и оценка упражнений используют одни организационные квоты. Каждой установке нужен выбор транспорта для всех текстовых сценариев.

**Решение.** Сервисы продолжают отправлять запросы в AI. После проверки квоты AI выбирает транспорт по `OPENAI_PROVIDER`. При `OPENAI_CODEX` он передаёт запрос внутреннему C#-сервису, где CodexNet запускает отдельный `codex exec`. В Compose к сети воркера подключён только AI. В режиме `OpenAi` или `F5Ai` AI обращается к настроенному HTTP API.

**Последствия.** Авторизация CLI принадлежит воркеру. Результат содержит финальный текст и расход токенов. Потоковый клиент в режиме Codex получает один фрагмент по завершении генерации. Вызов модели после ошибки требует нового запроса. [Внутренний маршрут](../contracts/http/codex.md) · [Настройка](../../infra/README.md).
