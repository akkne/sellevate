# Локальная модель для полных реплик в звонке

27 ноября 2026 года.

В тренировочном звонке ожидание полного текста от отдельного процесса Codex занимало около восьми секунд. Для локальных установок введён необязательный HTTP-клиент модели на Mac, которая остаётся загруженной между репликами. AI-сервис проверяет доступ к сессии и квоту, запрашивает полный ответ, учитывает токены и передаёт одну целую реплику действующему синтезатору. Выбор модели касается только голосового режима.

Оператор запускает процесс на хосте. При недоступности процесса голосовой запрос возвращается к провайдеру диалога. Постоянно загруженной модели требуется память Mac. Настройка по умолчанию использует прежний провайдер. [Эксплуатация и карточка модели](../integrations/local-qwen-voice.md)
