# Интерфейс Sellevate

Основные токены, утилиты Tailwind и компоненты оформления определены в [globals.css](../frontend/app/globals.css). `:root` задаёт светлую тему, `html[data-theme="dark"]` — тёмную. `@theme inline` связывает цвета с утилитами Tailwind. Для основного текста используется Hanken Grotesk с системным резервным шрифтом.

Используйте общие [кнопки, поля, значки и модальные окна](../frontend/shared/components). Для интерактивного статуса оставляйте подпись вместе с цветом. Руководителю организации интерфейс адресован на «вы». Загрузку, отсутствие данных, ошибку и готовый ответ показывайте раздельно. После фоновой ошибки сохраняйте ранее полученные данные и дайте повторить запрос.

Проверяйте доступное название поля, управление Tab и Enter, видимый фокус, контраст обеих тем, мобильную ширину и `prefers-reduced-motion`. Переключатели языка и темы сообщают свой выбор через доступное состояние. Брендовые файлы находятся в [публичных ресурсах](../frontend/public).
