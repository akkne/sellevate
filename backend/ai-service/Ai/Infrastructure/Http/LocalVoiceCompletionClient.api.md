# Полная реплика для локального звонка

AI-сервис вызывает `POST /v1/chat/completions` у запущенного оператором llama-server. В тестовой конфигурации используется `llama.cpp b12816` и одна из моделей Qwen3-4B-Instruct-2507 или Qwen3.5-9B в формате GGUF Q4_K_M. Сервер слушает loopback. В Docker Desktop адрес Mac доступен как `host.docker.internal`. Этот клиент работает без ключа облачного провайдера, HTTP-прокси и перенаправлений.

Запрос JSON включает выбранную модель, системную инструкцию и историю текущего диалога с ролями, температуру 0,3, `stream=false` и грамматику JSON в формате GBNF. Грамматика задаёт порядок полей и требует `endCallReason=null` у продолжающегося звонка. Окно тестового сервера составляет 16 384 токена на один одновременный запрос. Лимит генерации равен меньшему из 160 токенов и лимита диалога. Общее ограничение запроса и ответа в битах зависит от HTTP-сервера и токенизации. Контекст модели ограничивает текст, файлы не передаются.

Ответ содержит JSON в `choices[0].message.content` с репликой, признаком завершения и причиной завершения. AI проверяет завершённость, передаёт реплику на синтез целиком и записывает использование модели в журнал организации. При недоступности локального сервера, отказе по длине контекста, прерванной генерации или некорректном ответе используется основной провайдер диалога. Отмена звонка прерывает запрос. Вычисления расходуют память и ресурсы Mac, отдельной платы за токены локального сервера нет.
