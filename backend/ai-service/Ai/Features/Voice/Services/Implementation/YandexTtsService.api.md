# Синтез речи

`POST /speech/v1/tts:synthesize` отправляет текст и параметры голоса как форму с API-ключом. В конфигурации по умолчанию используются голос `marina`, язык `ru-RU`, формат `lpcm` и частота 48 кГц. Код оборачивает PCM в WAV для воспроизведения браузером и записывает расход по имени `yandex-tts`.

Лимит текста API v1 — 5000 символов. Размер WAV зависит от длительности записи. Общий предел запроса и ответа с заголовками в битах в описании метода не приведён. API синхронный, отмена передаётся через CancellationToken. Проверьте отказ авторизации, превышение квоты, пустой звук и корректность заголовка WAV. [Ограничения](https://aistudio.yandex.ru/ru/docs/speechkit/concepts/limits), [тарификация](https://aistudio.yandex.ru/ru/docs/speechkit/pricing).
