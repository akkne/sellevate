# Синтез речи Fish Audio

AI-сервис отправляет реплику по HTTPS методом `POST` на `https://api.fish.audio/v1/tts`. Запрос содержит Bearer-токен и заголовок `model: s2.1-pro-free`. JSON содержит текст, формат `pcm`, частоту 44 100 Гц и `reference_id` диктора. Для каждого фрагмента используется голос режима или, если Fish Audio ID отсутствует, один и тот же русский голос по умолчанию. Адаптер проверяет HTTP-статус и длину 16-битных отсчётов, формирует WAV с точными размерами секций для браузерного декодера и записывает количество символов в журнал использования организации. Отмена запроса распространяется на обращение к провайдеру. Ошибки синтеза обрабатывает существующий голосовой сценарий.

При `LowLatencyMp3=true` провайдер возвращает MP3 с параметрами `latency=low` и `mp3_bitrate=128`. Для потоковой доставки клиенту AI читает тело по мере поступления и учитывает синтез один раз.

[Спецификация Fish Audio](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)
