# Синтез речи Fish Audio

AI-сервис отправляет реплику по HTTPS методом `POST` на `https://api.fish.audio/v1/tts`. Запрос содержит Bearer-токен и заголовок `model: s2.1-pro-free`. JSON содержит текст, формат `wav` и необязательный `reference_id`. Адаптер проверяет HTTP-статус и сигнатуру RIFF/WAVE, затем записывает количество символов в журнал использования организации. Отмена запроса распространяется на обращение к провайдеру. Ошибки синтеза обрабатывает существующий голосовой сценарий.

[Спецификация Fish Audio](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)
