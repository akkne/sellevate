# Распознавание речи

Сервис отправляет один файл в multipart-запросе `POST /v1/audio/transcriptions`. Поля — `file`, `model`, `response_format`, `language`. Значения по умолчанию — `whisper-1`, `verbose_json`, `ru`. Ответ разбирается как JSON с текстовым `text` и необязательным `language`. Поддерживаемые расширения и MIME определяет [таблица форматов](../../Constants/TranscriptionAudioFormats.cs). Сервис принимает поток отмены.

У приложения задан предел файла 25 MiB. Провайдер указывает предел загрузки 25 MB. Размер файла и размер multipart вместе с заголовками различаются. Предельный размер всего HTTP-ответа в битах не указан. Выход зависит от продолжительности записи. Проверьте ошибку слишком большого файла, пустой результат, невалидный JSON, недоступность модели и учёт использования. [Контракт провайдера](https://developers.openai.com/api/docs/guides/speech-to-text).
